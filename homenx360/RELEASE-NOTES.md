# HomeNX360 NXE preview

Native NXE-inspired vertical channels, overlapping cards, animated focus and
channel switching, reflections, a compact Guide, and an original skippable
HomeNX startup. Libraries now scroll continuously beyond ten games.

Download `HomeNX360-preview.nro` to try first. `HomeNX360-update.zip` is the
SD-root update for an existing HomeNX installation. Read `INSTALL.md` for backup
and rollback instructions. `HomeNX360-source.zip` contains the corresponding
prepared source tree, including upstream submodules.

Experimental: no Switch hardware testing was performed. The user's Atmosphere
1.12.1 / system 22.5.0 configuration is not verified compatible. Startup is
inside HomeNX; bootloader/Atmosphere screens and Nintendo applets are unchanged.

This adapts NXE's visual language to Switch actions. It does not reproduce Xbox
Live, Marketplace, 3D Xbox avatars or proprietary Xbox startup audio/video.
See `NXE-REFERENCES.md` for the reference catalog and unavailable video downloads.
Exact executable hashes and daemon provenance are in `BUILD-MANIFEST.json`.
